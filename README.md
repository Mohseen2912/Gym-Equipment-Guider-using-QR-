#  Gym Equipment Guider (Using QR Code)

A smart gym assistance system that helps users understand how to use gym equipment by scanning QR codes attached to machines.

The project provides exercise guidance, safety instructions, muscle information, and workout tutorials instantly through QR technology.

---

#  Features

##  QR Code Based Access
- Scan QR codes attached to gym machines
- Instantly open exercise guidance page

##  Equipment Information
- Equipment name
- Usage instructions
- Target muscle groups
- Recommended posture
- Safety precautions

##  Workout Guidance
- Exercise demonstration videos
- Step-by-step workout process
- Beginner-friendly instructions

##  User Friendly Interface
- Simple and responsive UI
- Mobile-friendly design
- Fast navigation

---

#  Purpose of the Project

Many beginners in gyms do not know:
- How to use equipment properly
- Which muscles are targeted
- Correct exercise posture

This project solves that problem using QR technology and digital guidance.

---

#  Technologies Used

- HTML5
- CSS3
- JavaScript
- C#
- .NET
- MySQL
- QR Code Generator API

---

#  How It Works

1. User scans QR code on gym equipment
2. QR redirects to equipment guide page
3. User views:
   - Instructions
   - Workout steps
   - Safety tips
   - Demo videos
